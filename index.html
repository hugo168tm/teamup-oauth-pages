應用程式用途 / Purpose of this application

「TeamUp 的士預約助手」係一個供車隊營運者私人使用嘅的士預約管理工具。車隊營運者透過通訊軟件（例如 Discord）傳送乘客嘅輪椅的士預約資料（上車地點、目的地、日期時間、聯絡人姓名及電話號碼）畀本應用程式，應用程式會自動將預約寫入車隊嘅 TeamUp 日曆，並將乘客聯絡電話同步至車隊營運者本人嘅 Google 通訊錄（電話簿），方便車隊聯絡乘客及安排車輛。

TeamUp Taxi Booking Assistant is a private taxi booking management tool used solely by the fleet operator. The operator sends wheelchair taxi booking details (pickup location, destination, date/time, contact name and phone number) to this application via messaging software (e.g. Discord). The application automatically writes the booking into the fleet's TeamUp calendar and syncs the passenger's contact phone into the operator's own Google Contacts, so the fleet can contact passengers and arrange vehicles.

資料處理 / Data handling

本應用程式只會處理車隊營運者自己輸入嘅預約資料，唔會收集任何其他使用者嘅個人資料，亦冇公開註冊或登入功能。所有資料都儲存於車隊營運者自己擁有嘅 Google 帳戶及 TeamUp 日曆內。

This application only processes booking data entered by the fleet operator itself. It does not collect personal data from any other users and offers no public registration or login features. All data is stored within the operator's own Google account and TeamUp calendar.
